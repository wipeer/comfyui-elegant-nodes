# Elegant Boolean Switch

An on/off switch that outputs `true` or `false`.

### Controls

| Item | Description |
|---|---|
| **value** | The switch: `true` or `false`. This is the output when nothing is connected to the input. |

Connect a **BOOLEAN** to **value** and that value is passed on instead of the switch (the switch stays as you left it, and is used again when you disconnect the link).

### Outputs

| Item | Description |
|---|---|
| **boolean** | The connected boolean, or the switch when nothing is connected (BOOLEAN). |
